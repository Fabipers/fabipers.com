Si trabajas comprando tráfico y optimizando conversiones, tu navegador es tu principal herramienta de trabajo. Estas son las extensiones obligatorias para auditar cuentas y asegurar que tu tracking funciona a la perfección.

## 1. Meta Pixel Helper
![Meta Logo](/images/extensions/meta.svg)

Es el detector de mentiras oficial de Facebook. Te permite ver en tiempo real si el Píxel de Meta está instalado correctamente, qué eventos se disparan y qué parámetros se envían.
[Descargar Meta Pixel Helper](https://chrome.google.com/webstore/detail/meta-pixel-helper/fdgfkebigiimkdachdlmghodagkhkoba)

## 2. Google Tag Assistant (Companion)
![Google Logo](/images/extensions/google.svg)

Imprescindible para auditar infraestructuras de Google. Funciona en conjunto con el modo "Preview" de Google Tag Manager para diagnosticar instalaciones de GA4 y conversiones. 
[Descargar Tag Assistant](https://chrome.google.com/webstore/detail/tag-assistant-companion/jmekfmbnaedglfnkikiejghmjiepnelm)

## 3. Wappalyzer
![Wappalyzer Logo](/images/extensions/wappalyzer.svg)

La herramienta de espionaje técnico. Escanea el código del sitio web y te dice qué CMS usan, qué analítica tienen y qué pasarela de pagos utilizan. Ideal para auditar prospectos.
[Descargar Wappalyzer](https://chrome.google.com/webstore/detail/wappalyzer-technology-pro/gppongmhjkpfhphmomedafcmligbkjcg)

## 4. UTM.io - UTM Builder
![UTM.io Logo](/images/extensions/utm.svg)

Construye URLs etiquetadas (`utm_source`, `utm_medium`) directamente desde la barra de tu navegador, guardando plantillas para estandarizar la medición de tus campañas.
[Descargar UTM.io](https://chrome.google.com/webstore/detail/utmio-google-analytics-ur/eippneebkepbmpiaedoldgjhpcncicdg)

## 5. ColorZilla
![ColorZilla Logo](/images/extensions/colorzilla.svg)

Este gotero avanzado te permite extraer el código Hexadecimal de cualquier elemento en una página web al instante. Perfecto para armar landings rápidas que hagan match con la marca de tu cliente.
[Descargar ColorZilla](https://chrome.google.com/webstore/detail/colorzilla/bhlhnicpbhignbdhedgjhgdocnmhomnp)
